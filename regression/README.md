## 🛡️ วิธีใช้ leak_check.py (ตรวจว่าโมเดลโกงหรือเปล่า)

### รัน

```sh
python leak_check.py                              # ใช้ค่าในไฟล์ (data.csv / price_thousand_thb)
python leak_check.py loan_data.csv int.rate       # ระบุไฟล์ + target เอง
```

> ไฟล์/target default แก้ได้ที่บล็อก `# ===== CONFIG (แก้ตรงนี้) =====` ใน leak_check.py

### มันตรวจอะไรให้ (6 ชั้น)

| ชั้น | ตรวจว่า | ควรทำอะไรถ้าเจอ |
|---|---|---|
| 1 | แถวซ้ำทั้งแถว | ปล่อย (my_run ตัดให้แล้ว) |
| 2 | แถวเดียวกันรั่วข้าม train/test | ต้อง 0 — ถ้าไม่ใช่แปลว่าข้อมูลต้องทำความสะอาดก่อน |
| 3 | feature ที่ \|corr\| > 0.95 กับ target | **ตัดทิ้งทันที** (มันคือสำเนาคำตอบ) |
| 4 | Ablation ตัดทีละ feature | ดูว่าตัวไหน "แบกคะแนน" ทั้งโมเดล → ต้องเช็กด้วยความรู้ธุรกิจ (ดูหมายเหตุข้างล่าง) |
| 5 | Prune candidate | ตัวไหนตัดแล้ว CV ดีขึ้น → ควรตัด (ตัดสินจาก CV บน train เท่านั้น — ปลอดภัย) |
| 6 | Overfit (train − test > 0.10) | ลดความซับซ้อน / เพิ่มข้อมูล |

### ⚠️ กฎการอ่าน ablation ที่สำคัญที่สุด

การที่ "ตัด feature แล้วคะแนนตกฮวบ" **ไม่ได้แปลว่า leak เสมอ** ต้องถามว่า feature นั้นคืออะไร:

- **สาเหตุจริงของ target** (รู้ก่อนเกิดผล) → เก็บไว้ เช่น `fico` (credit score) กับดอกเบี้ย
- **ฟังก์ชัน/ผลลัพธ์ของ target** (เกิดหลัง target) → **leak ต้องตัด** เช่น `installment` (ค่าผ่อน = คำนวณ*จาก*ดอกเบี้ย)

> ตัวอย่างจริงจาก loan_data.csv: leak_check ตรวจเจอ `installment` (ตัดแล้ว R² ตก 0.093) และ `fico` (ตก 0.223) —
> `installment` คือ leak ต้องตัด / `fico` คือตัวจริงเก็บไว้ — CV ไม่สามารถแยก 2 กรณีนี้ให้ได้ ต้องใช้ความรู้ธุรกิจ

## 🧮 โมเดล 3 ตัวต่างกันยังไง

| โมเดล | คลาส | ใช้เมื่อไหร่ | จุดเด่น |
|---|---|---|---|
| Simple Linear | `LinearRegression` | อยากดูความสัมพันธ์ 1 คู่ ง่าย ๆ | อ่านง่าย ทำกราฟสวย |
| Multiple Linear | `MultipleLinearRegression` | ต้องการทำนายจากหลายปัจจัย | แม่นสุดถ้าความสัมพันธ์เป็นเส้นตรง |
| Polynomial | `PolynomialRegression` | ความสัมพันธ์โค้ง (ไม่เป็นเส้นตรง) | เลือก degree เองด้วย 5-fold CV + กฎ 1-SE (กัน overfit ในตัว) |

### เรียกใช้โมเดลเดี่ยวด้วยตัวเอง (ไม่ผ่าน my_run)

```python
import numpy as np
from multiple_linear_regression import MultipleLinearRegression

m = MultipleLinearRegression()      # test_size=0.2, seed=42
m.set_data(X, y, feature_names)     # X: (n, พจน์), y: (n,), ชื่อคอลัมน์
m.split()                           # แบ่ง train/test (seed คงที่ — ซ้ำได้ผลเดิม)
w = m.fit_normal_equation()         # w[0]=intercept, w[1..]=coef

print(m.metrics(m.y_test, m.predict(m.X_test, w)))   # {"r2","mse","mae"}
```
